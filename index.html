Security check for AI-built sites

How to test each one, and what to paste into your AI to fix it.

Full prompt for building something new 
My startup: [what it does]
Users: [who logs in, what they can do]
Tech: [e.g. PHP + MySQL, Next.js + Supabase]

Build this secure by default:
- Hash passwords (bcrypt or argon2)
- Limit login attempts: 5 tries, then lock 15 min
- Every page and API route checks the user owns the data it returns
- Admin routes need an admin role
- Supabase/Firebase: Row Level Security on every table with real policies
- Prepared statements for all database queries
- Escape all user input before showing it
- CSRF protection on forms that change data
- API keys and passwords in .env, never in frontend code or Git
- Database uses its own user with a strong password
- Error pages don't show code or database details
- Don't reveal if an email is already registered

When done, list every security risk still left and what I need to set up before launch.
Prompt for reviewing code you already have 
Review this code for security problems before it goes live. Check:
- Can one user see or change another user's data?
- Are login, password reset and sessions safe?
- Are API keys or passwords exposed?
- Is user input validated and escaped?
- Do forms have CSRF protection?
- Are database rules and permissions correct?

For each problem: explain it simply, rate it high/medium/low, show the fix. Don't say it's secure unless you checked every point.
