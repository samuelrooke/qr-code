Prompt for adding a database 
I need to add a database to my startup's website, so it can save things like sign-ups or messages.

What the site does: [short description]
What I need to save: [e.g. contact form messages, user accounts, bookings]
Who should be able to see it: [e.g. only me / each user only their own data]
How the site is built now: [e.g. GitHub Pages, WordPress, Next.js, made with Lovable]

Please set it up safely:
- Suggest a simple option that fits my site and explain why
- Only save what I listed, nothing extra
- Nobody can see or change the data unless they're allowed to, from day one (if you use Supabase or Firebase, set up the access rules for every table)
- Keep secret keys hidden, never in the website's code
- Check what people send before saving it
- Stop the form from being spammed

Explain each step simply, as if I've never done this before.
At the end, show me how to test that a stranger can't see the data.
Prompt for building something new safely 
My startup: [what it does]
Who uses it: [who logs in and what they can do]
How it's built: [e.g. PHP + MySQL, Next.js + Supabase, Lovable]

Build this so it's safe from the start:
- Users can only see and change their own data. Check this on every page, not just that they're logged in
- Only admins can open admin pages, and this is checked behind the scenes, not just by hiding buttons
- If you use Supabase or Firebase, set up access rules for every table so people only reach their own data
- Block or slow down repeated wrong passwords
- Password reset links expire and only work once
- Logins time out, and logging out really ends the session
- Double-check everything people send before saving it, and show what they type as plain text
- Protect forms from being sent by other websites
- Uploads: only the file types I need, with a size limit
- Keep all secret keys hidden, never in the website's code or on GitHub
- Only use well-known, up-to-date add-ons

When you're done, list anything that's still not safe and what I need to set up before launch.
Prompt for checking code you already have 
Check this code for security problems before it goes live.

Look for:
- Can one user see or change another user's data?
- Are logging in, password reset and logging out safe?
- Are any secret keys or passwords visible?
- Is everything people send checked, and shown as plain text?
- Can other websites send forms as my users?
- Are the database access rules set up correctly?
- Are any add-ons old or unknown?

For each problem: explain it in simple words, say how serious it is (high, medium or low), and show the fix.
Don't tell me it's safe unless you've checked every point.
